The software for A3 can be downloaded [here](201A3_BLE_server.zip). <br> 
The codebase's version history can be found on [github](https://github.com/nsgarde/ESP_BLE_server.git). <br>
The software requires the Micropython firmware for ESP32-S3 and the aioble library (available through the mip package manager). <br>
*Since Python syntax is dependant on indenting, operating systems using non-standard UTF-8 encoding may not display files properly. If you use Microsoft Windows or Apple OSX, please use the provided dos version of the file. Linux or BSD users can use the non-dos marked file without issues.* </br>
